# روباهیو — Mini App Final

## تغییرات این نسخه
- صفحه لودینگ سریع و سبک قبل از ورود به مینی‌اپ
- نوار پیشرفت و وضعیت آماده‌سازی
- افکت صوتی داخلی با Web Audio؛ بدون فایل صوتی حجیم
- صدای گردونه، صدای جایزه و صدای انفجار بمب
- افکت انفجار تمام‌صفحه هنگام خوردن بمب: فلش، موج شوک، دود و BOOM
- لرزش Telegram هنگام انفجار
- رعایت prefers-reduced-motion و حالت سبک دستگاه‌های ضعیف
- APIها و مسیرهای فعلی گردونه، بمب، درس، چت و پروفایل حفظ شده‌اند

## دیپلوی
فایل `index.html` را جایگزین نسخه فعلی Mini App کن. `education.py` و `bridge.py` همان فایل‌های فعلی پروژه هستند و در ZIP قرار داده شده‌اند.

نکته: مرورگرهای موبایل اجازه پخش صدای خودکار قبل از تعامل کاربر را محدود می‌کنند؛ موتور صدا با اولین لمس/کلیک کاربر Unlock می‌شود و بعد افکت‌های بازی بدون دانلود فایل صوتی اجرا می‌شوند.
