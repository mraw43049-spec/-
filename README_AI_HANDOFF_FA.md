# بستهٔ ضروری روباهیو — راهنمای تحویل به هوش مصنوعی

## هدف این بسته
این پروژه ربات تلگرام روباهیو و Mini App آن است. این ZIP عمداً فایل‌های تاریخچه/CHANGELOG، نسخهٔ تکراری قدیمی `bot-1.py` و مستندات پراکنده را ندارد؛ سورس‌های فعال و فایل‌های لازم برای اجرا و ویرایش باقی مانده‌اند.

## فایل‌های اصلی
- `bot.py`: منطق اصلی ربات تلگرام، بانک روبی، بازی‌ها، کازینو، تأییدها و دکمه‌ها.
- `main.py`: API و سرویس وب Mini App؛ اجرای ASGI با `uvicorn main:app`.
- `index.html`, `style.css`: رابط Mini App.
- `database.py`: مدل‌ها و اتصال دیتابیس؛ دیتابیس واقعی از متغیر محیطی می‌آید.
- `config.py`: تنظیمات و متغیرهای محیطی. توکن‌ها و اطلاعات محرمانه را داخل ZIP قرار ندهید.
- `auth.py`: اعتبارسنجی دادهٔ تلگرام Mini App.
- `education.py`, `bridge.py`, `ruby_emojis.py`, `game_logic.py`, `attack_owl.py`, `fox_brain.py`, `fox_spell.py`, `ai_service.py`: ماژول‌های مورد استفادهٔ ربات.
- `migrate_db.py`: ابزار مهاجرت دیتابیس؛ قبل از اجرای مهاجرت روی دیتابیس اصلی، از دیتابیس پشتیبان بگیرید.
- فایل‌های تصویر/GIF/WebP/WebM: دارایی‌های تصویری استفاده‌شده در ربات و بازی‌ها؛ حذفشان ممکن است تصاویر یا قابلیت‌های مربوط را خراب کند.
- `requirements.txt`: وابستگی‌ها.

## تغییرات رنگ دکمه‌ها
- دکمه‌های پنل بانک روبی آبی (`primary`) هستند.
- برداشت از بانک روبی قرمز (`danger`) است؛ بازگشت/لغو نیز قرمز می‌شود.
- منوهای بازی روبی و کازینو روبی آبی (`primary`) هستند.
- دکمه‌های تأیید/بله/قبول سبز (`success`) و رد/خیر/لغو/بازگشت/حذف قرمز (`danger`) هستند.
- برای حفظ سازگاری با دکمه‌های قدیمی، رنگ‌ها به‌صورت خودکار بر اساس متن و `callback_data` تعیین می‌شوند؛ در صورت وجود `style` صریح، آن مقدار حفظ می‌شود.
- این قابلیت به نسخهٔ جدیدتر `python-telegram-bot` نیاز دارد؛ وابستگی در `requirements.txt` روی `>=22.5,<23` تنظیم شده است. رنگ‌ها فقط در کلاینت‌هایی دیده می‌شوند که Telegram Bot API و رابط کاربری‌شان از button style پشتیبانی کنند.

## راه‌اندازی
1. متغیرهای محیطی فعلی Railway را حفظ کنید؛ به‌خصوص `BOT_TOKEN` و `DATABASE_URL` و هر متغیر تنظیماتی دیگری که در سرویس فعلی وجود دارد.
2. سرویس ربات را طبق تنظیم فعلی با فایل اصلی ربات (`bot.py`) اجرا کنید.
3. برای Mini App، سرویس ASGI را با `uvicorn main:app --host 0.0.0.0 --port $PORT` اجرا کنید. در Railway معمولاً بهتر است ربات و API مینی‌اپ در سرویس‌های جدا اجرا شوند، مگر آنکه پروژه از قبل روش دیگری داشته باشد.
4. قبل از جایگزینی فایل‌های تولیدی، از دیتابیس نسخهٔ پشتیبان بگیرید. این بسته هیچ دیتابیس زنده یا توکن محرمانه‌ای در خود ندارد.

## نکته برای هوش مصنوعی بعدی
قبل از تغییر منطق پرداخت، بانک، انتقال روب‌پوینت یا دیتابیس، مسیرهای موجود در `bot.py` و مدل‌های `database.py` را دنبال کن و از بازنشانی یا ساخت دیتابیس جدید خودداری کن. تغییرات را در فایل‌های فعال اعمال کن، نه در `bot-1.py` که نسخهٔ قدیمی و حذف‌شده از بسته است.
