فایل جدید selftools.py رو کنار بقیه فایل‌ها بذار (وابستگی جدیدی لازم نیست). دستورها فقط با نقطه کار می‌کنن و بین اسم دستور و متن یه فاصله بذار.
- ماشین‌حساب: .حساب 25*4+10   (ریپلای روی پیام هم کار می‌کنه؛ جمع، تفریق، ضرب، تقسیم، توان ^ ، درصدِ باقی‌مانده %، sqrt/abs/round/ln/log، اعداد فارسی)
- قیمت: .قیمت (خلاصه) | .قیمت دلار / یورو / پوند / درهم / لیر / طلا / سکه | .قیمت بیتکوین / اتریوم / تتر / تون / ریپل / سولانا / دوج / ترون / بایننس
  منبع ارز/طلا/سکه tgju.org (غیررسمی و به ریال، نمایش به تومان) و ارز دیجیتال CoinGecko. اگه tgju برای IP سرور بسته بود، متغیر اختیاری PRICE_API_URL رو روی یه آدرس هم‌ساختار بذار.
- تاریخ: .تاریخ (شمسی/میلادی/قمری تقریبی/ساعت تهران) | .تاریخ 1405/8/5 یا .تاریخ 2026-10-27 برای تبدیل.
- اوقات شرعی: .اذان | .اذان مشهد   (۳۱ شهر؛ شهر پیش‌فرض از پنل ← امکانات بیشتر ← صفحهٔ ۲؛ روش مؤسسهٔ ژئوفیزیک دانشگاه تهران از Aladhan)
- کوتاه‌کنندهٔ لینک: .کوتاه https://... (یا ریپلای روی پیام لینک‌دار؛ تا ۳ لینک) با is.gd و در صورت خطا TinyURL.
- ذخیرهٔ استوری: .استوری (ریپلای روی استوری فورواردی/منشن‌شده) یا .استوری t.me/username/s/123 → Saved Messages. استوری‌های «محافظت از محتوا» ذخیره نمی‌شن؛ استوری باید برای اکانتت قابل مشاهده و منقضی‌نشده باشه.
- سکوت: .سکوت (ریپلای روی پیام کاربر؛ توی پی‌وی بدون ریپلای هم می‌شه) | .سکوت خاموش یا .رفع سکوت. توی پی‌وی پیام‌های جدیدِ کاربر ساکت‌شده فقط از سمت خودت پاک می‌شه؛ توی گروه‌ها فقط اعلان‌های سلف (منشن‌گیر/ناظر) براش قطع می‌شه. لیست و دکمهٔ روشن/خاموش: پنل ← امکانات بیشتر ← صفحهٔ ۲ ← مدیریت سکوت (حداکثر ۳۰ نفر؛ افزودن با آیدی عددی یا @یوزرنیم هم ممکنه).
- بلاک سریع: .بلاک (ریپلای) | .رفع بلاک — بلاک واقعی تلگرام.
- «امکانات بیشتر» حالا دو صفحه داره (◀ قبل / بعد ▶) و راهنمای ابزارها داخل صفحهٔ ۲ هست. فهرست کوتاه دستورها هم توی «دستورات سلف» اضافه شد.
- محدودیت: ۲۰ دستور ابزار در دقیقه برای هر کاربر (برای محافظت از اکانت و سرویس‌های بیرونی).
- توجه: ابزارهای قیمت/اذان/کوتاه‌کن به اینترنت و سرویس‌های بیرونی وابسته‌ان؛ قبل از استفادهٔ واقعی یه بار روی Railway امتحانشون کن و لاگ‌ها رو ببین.

فایل‌های این پوشه را در ریشه ریپوی GitHub قرار بده و در Railway دیپلوی کن.
متغیرها: BOT_TOKEN, SELF_API_ID, SELF_API_HASH, SELF_KEY و ترجیحاً DATABASE_URL برای PostgreSQL پایدار.
Start Command: python main.py

تغییرات:
- دستورهای .ریاکشن، .ایموجی و .ساعت (و .غیرفعال ساعت) دوباره توی چت‌ها کار می‌کنن. تنظیم کلمه/زمان/گپ/دکمهٔ بازی‌ها همچنان فقط از پنل انجام می‌شه.
- رفع باگ: دستور .کپی (ریپلای روی پیام کاربر) و .غیرفعال کپی دوباره کار می‌کنن؛ قبلاً پیام دستور بی‌صدا پاک می‌شد و کاری انجام نمی‌شد.
- پنل پشتیبانی: رسیدها حالا با خود عکس/فایل رسید نشون داده می‌شن؛ پشتیبان اول «من بررسی می‌کنم» رو می‌زنه، اسمش روی رسید می‌افته و بقیه نمی‌تونن همزمان تأییدش کنن (ادمین همیشه می‌تونه).
- تیکت پشتیبانی: کاربر از منوی ربات «تیکت پشتیبانی» رو می‌زنه و هر نوع پیام (متن/عکس/ویس/ویدیو/فایل) می‌فرسته؛ پشتیبان‌ها از /support ← «تیکت‌های باز» یا از همون پیام اعلان، با دکمهٔ «پاسخ» جواب می‌دن (با هر نوع مدیا) و تیکت رو می‌بندن. کاربر با «ادامه گفتگو» ادامه می‌ده.
- پیام همگانی برای پشتیبانی هم باز شد (دکمهٔ «پیام همگانی» توی /support): هر نوع مدیا (عکس، ویدیو، گیف، ویس، آهنگ، ویدیو مسیج، فایل، استیکر) و متن با فرمت تلگرام (بولد، ایتالیک، کد، اسپویلر، لینک…) همون‌طور کپی می‌شه، با امکان افزودن دکمهٔ لینک. گزارش نتیجه برای فرستنده و ادمین می‌ره.
- قفل دکمه‌ها: پنل‌هایی که با «.پنل» توی چت‌ها باز می‌شن فقط برای صاحبشون کار می‌کنن؛ اگه کس دیگه‌ای دکمه بزنه پیام «این پنل مال کس دیگه‌ایه» می‌گیره و هیچ تغییری اعمال نمی‌شه. پنل‌های قدیمیِ بدون قفل هم غیرفعال‌ان (دوباره .پنل بنویس). هر کاربر باید خودش سلف رو فعال کنه.
- پنل پشتیبانی (/support) بازنویسی شد و فقط برای پشتیبان‌ها و ادمین باز می‌شه: رسیدهای در انتظار با دکمهٔ تأیید/رد، بررسی کاربر با آیدی (موجودی، وضعیت سلف، آخرین پرداخت‌ها). پشتیبان‌ها رو با متغیر SUPPORT_IDS (آیدی عددی با کاما) توی Railway بذار؛ رسیدها برای ادمین و پشتیبان‌ها می‌رسه. پشتیبان به منوی ادمین، آمار، اطلاعیه و کدها دسترسی نداره.
- کد تخفیف خرید الماس: ادمین /admin ← «ساخت کد تخفیف» (مثلاً 20 10 یعنی ۲۰٪ برای ۱۰ نفر؛ سومی اختیاری = ساعت اعتبار). کاربر در «خرید الماس» ← «کد تخفیف» واردش می‌کند؛ مبلغ نهایی به کاربر و ادمین نشان داده می‌شود. اگر رسید رد شود، مصرف کد برمی‌گردد.
- آمار ادمین (/admin ← «آمار ربات»): کاربران، فروش، الماس، پرمصرف‌ترین قابلیت‌ها.
- اطلاعیهٔ همگانی (/admin ← «اطلاعیهٔ همگانی»): هر نوع پیام (متن/عکس/فایل) را به همهٔ کاربران یا فقط کاربران سلف فعال کپی می‌کند و گزارش می‌دهد.
- هشدار کمبود الماس: وقتی سلف روشن است و الماس کمتر از ۲۴ ساعت (و بار دوم کمتر از ۳ ساعت) کفایت می‌کند، به کاربر با دکمهٔ خرید خبر می‌رود.
- فایل جدید extras.py (کنار بقیه فایل‌ها بذار): پاسخ خودکار، ذخیره/اعلان پیام حذف‌شده و ویرایش‌شده (فقط پی‌وی)، ذخیرهٔ خودکار مدیای تایمردار (+ دستور .ذخیره با ریپلای)، منشن‌گیر، ناظر کلمه/@یوزرنیم/آیدی. همه از پنل ← «امکانات بیشتر».
- کد هدیه: ادمین در /admin ← «ساخت کد هدیه» (مثلاً 100 5 یعنی ۱۰۰ الماس برای ۵ نفر؛ سومی اختیاری = ساعت اعتبار)؛ کاربر از منوی ربات ← «کد هدیه» واردش می‌کند. جدول‌های جدید خودکار ساخته می‌شوند.
- متن خوش‌آمد /start بازطراحی شد (امکانات، هزینه‌ها، موجودی و وضعیت الماس).
- بدون الماس (حداقل ۵) سلف فعال نمی‌شود؛ دورهٔ رایگان ۳ روزه به‌صورت پیش‌فرض خاموش است (برای روشن‌کردن: متغیر SELF_TRIAL=1). با خاموش‌کردن سلف یا تمام‌شدن الماس، دسترسی هم بسته می‌شود.
- نوشتن «موجودی» در هر چت: ربات روی همان پیام ریپلای می‌کند «💰 موجودی شما» با دکمهٔ مقدار الماس زیرش (فقط صاحب پیام می‌تواند بزند).
- بعد از وصل‌شدن اکانت، به‌جای متن توضیحی بلند، همان پنل اصلی (.پنل) ارسال می‌شود؛ همیشه آنلاین، تایپینگ، حالت متن، راهنمای ترجمه و راهنمای تگ مستقیم داخل همین پنل هستند.
- تنظیمات کلمه/زمان/دکمه/گپ فقط از پنل انجام می‌شود؛ فرمان‌های قدیمی تنظیمات در چت‌ها نادیده گرفته و حذف می‌شوند.
- پس از تأیید عضویت کانال‌ها، کاربر واجد شرایط ۷۲ ساعت آزمایشی می‌گیرد.
- پس از پایان ۷۲ ساعت، سلف به‌صورت خودکار متوقف می‌شود و پیام شارژ الماس ارسال می‌شود.
- دعوت با لینک اختصاصی: پس از تأیید عضویت، هر دو طرف ۵۰ الماس می‌گیرند و اعلان دریافت می‌کنند.
- شماره کارت با فاصله‌های تک‌فاصله‌ای نمایش داده می‌شود.
- فقط شناسه 7433300089 مدیر اصلی است.
- حالت متن برای لاتین از حروف یونیکد استایل‌دار و برای فارسی از قالب‌بندی بولد/ایتالیک/مونو تلگرام استفاده می‌کند.

محدودیت‌های اعلام‌شده:
- قابلیت «همیشه آنلاین» هنگام اتصال سلف، درخواست تازه‌سازی وضعیت آنلاین را هر ۱۲۰ ثانیه می‌فرستد؛ تضمین نهایی آنلاین‌ماندن به محدودیت‌های تلگرام بستگی دارد.
- برای تایپینگ، از «تنظیمات تکمیلی» مقصد را انتخاب کن؛ هنگام دریافت رویداد تایپ در گفتگوها، وضعیت تایپ برای چند ثانیه در مقصد انتخابی نشان داده می‌شود. برای انتخاب مقصد باید اکانت سلف وصل باشد.
- دکمه‌های تلگرام از نظر API متن بولد واقعی ندارند.
- قبل از استفاده واقعی، اجرای آزمایشی روی Railway و بررسی لاگ‌ها ضروری است.
