# بات هور — Railway Ready

این نسخه Build را از PostgreSQL/psycopg مستقل می‌کند و به‌صورت پیش‌فرض با SQLite اجرا می‌شود؛ بنابراین خطای نصب `psycopg2/psycopg` در Build رخ نمی‌دهد.

## Railway Variables
- `BOT_TOKEN` = توکن بات
- `ADMIN_IDS` = آیدی عددی ادمین (مثلاً `123456789`؛ چند ادمین با کاما)
- `REQUIRED_CHANNEL=@fox_frenzy`
- `REQUIRED_CHANNEL_URL=https://t.me/fox_frenzy`
- `DATABASE_URL=sqlite:///bot.db`

## مهم
بات را در `@fox_frenzy` ادمین کن تا بتواند عضویت کاربران را بررسی کند.
ادمین‌های تعریف‌شده در `ADMIN_IDS` برای ورود به پنل مدیریت نیاز به عضویت کانال ندارند.

## امکانات
- عضویت اجباری قبل از استفاده
- دستور «هور» با cooldown
- موجودی، کل پوینت کسب‌شده، لول و فاصله تا لول بعد
- بازی‌های Telegram بدون شرط‌بندی و با پاداش ثابت
- پنل مدیریت: آمار، کاربران، پیام همگانی، دادن/کم‌کردن پوینت و تنظیم لول

برای نگهداری دائمی SQLite روی Railway، یک Volume به سرویس وصل کن و فایل `bot.db` را در همان مسیر نگه دار.
