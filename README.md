# بات هور — نسخه گروهی V4

## اجرای بازی در گروه
1. بات را به گروه اضافه کنید.
2. در @BotFather بخش Group Privacy را خاموش کنید (برای دریافت پیام‌های معمولی؛ دستورات بدون آن هم کار می‌کنند).
3. بات را در کانال @fox_frenzy ادمین کنید تا بتواند عضویت را بررسی کند.
4. در گروه روی پیام یک کاربر Reply کنید و بزنید:
   `/challenge dice`
5. کاربر دوم دکمه «قبول می‌کنم» را می‌زند.
6. هر بازیکن دکمه مخصوص خودش را می‌زند و بات نتیجه را در همان گروه اعلام می‌کند.

## دستورات
- `/start` شروع
- `/profile` آمار کاربر
- `/games` یا `/game` منوی بازی
- `/challenge dice` دعوت حریف با Reply
- ارسال «هور» برای دریافت پوینت طبق زمان‌بندی
- `/admin` پنل مدیریت

بازی‌ها بدون شرط‌بندی و انتقال پوینت بین بازیکنان هستند.
