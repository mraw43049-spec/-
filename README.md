# مینی‌اپ روبی — نسخه ارتقایافته

این نسخه روی همان دیتابیس بات اصلی کار می‌کند و داده‌های قبلی را حذف یا جایگزین نمی‌کند.

## ساختار
```text
project-root/
  bot.py
  database.py
  miniapp/
    backend/
      main.py
      auth.py
      requirements.txt
      .env.example
    frontend/
      index.html
```

## چه چیزهایی اضافه شده؟
- صفحه «🦊 روباه من» به‌جای اینکه فقط لیدربرد باشد.
- نمایش نام روباه، سطح، روب‌پوینت، شکم، رتبه و جنسیت در صورت وجود در مدل User.
- نمایش اسکین فعال و تصویر اسکین در صورت وجود فیلدهای مربوط به skin در مدل User.
- نمایش ایموجی فعال و داده‌های skin/emoji موجود در مدل User بدون حدس‌زدن نام فیلدها.
- لیدربرد ۵گانه قبلی حفظ شده است.
- دکمه‌های روباه، روب روب، شکار، بازی روبی، فروشگاه روبی، ازدواج روبی، روباهیو درس و پشتیبانی به UI اضافه شده‌اند.
- احراز هویت همان HMAC-SHA256 روی Telegram initData باقی مانده است.
- هیچ endpoint جدیدی برای تغییر مستقیم موجودی، سطح، ازدواج، اسکین یا cooldown ایجاد نشده؛ بنابراین این مینی‌اپ بدون دیدن `bot.py` و `database.py` نمی‌تواند منطق واقعی اقتصاد بات را حدس بزند یا داده‌ها را خراب کند.

## نکته مهم درباره «اجرای واقعی دکمه‌ها»
فایل‌های آپلودشده شامل `bot.py` و `database.py` نیستند. مینی‌اپ از `database.py` فقط برای خواندن اطلاعات استفاده می‌کند و منطق واقعی دکمه‌های بات در اختیار این نسخه نیست.

در فرانت‌اند، کلیک روی دکمه‌ها به‌صورت `ruby_fox_action` آماده شده است. اگر Mini App از `KeyboardButton` باز شود و Telegram `sendData` را در آن context فعال کند، این payload به بات ارسال می‌شود؛ بات باید `web_app_data` را دریافت و action را به handler واقعی خودش وصل کند.

اگر Mini App از BotFather Menu Button باز شود، Telegram تحویل `sendData` را برای این سناریو تضمین نمی‌کند. برای اجرای واقعی همان handlerهای موجود بات، باید `bot.py` هم در اختیار باشد تا اتصال بدون تغییر منطق اقتصادی بات انجام شود.

## Railway
مطابق ساختار قبلی:
- Root Directory: `miniapp/backend`
- Start Command:
```bash
uvicorn main:app --host 0.0.0.0 --port $PORT
```
- Variables:
  - `BOT_TOKEN`
  - `DATABASE_URL`

این دو مقدار باید دقیقاً با سرویس اصلی بات یکی باشند.

## حفظ دیتای کاربران
این نسخه هیچ drop/delete/migration destructive روی دیتابیس انجام نمی‌دهد و فقط رکورد کاربر را می‌خواند. بنابراین جایگزین کردن این پوشه، به‌خودی‌خود حساب‌ها، روب‌پوینت‌ها، جام‌ها، دوستان، رسیدها یا سایر داده‌های بات را حذف نمی‌کند.
