# نسخه اصلاح‌شده بات هور

این نسخه برای Railway آماده شده است.

## تغییرات مهم
- عضویت اجباری در `@fox_frenzy` از همان `/start`
- تا عضویت تأیید نشود هیچ قابلیت اصلی بات قابل استفاده نیست.
- دستور «هور» با cooldown و نمایش موجودی، کل هور پوینت کسب‌شده و فاصله تا لول بعد
- سطح‌بندی و باز شدن بازی‌ها
- بازی‌های دونفره بدون شرط‌بندی: برنده/بازنده پاداش ثابت می‌گیرند.
- پنل ادمین:
  - آمار کلی
  - تعداد کاربران
  - پیام همگانی
  - افزودن/کم‌کردن هور پوینت
  - تنظیم سطح
- migration خودکار ستون `total_earned`
- رفع مشکل build وابستگی `psycopg2-binary` با استفاده از `psycopg[binary]` که با SQLAlchemy سازگار است.

## متغیرهای Railway
این‌ها را در Variables سرویس بات بگذار:
- `BOT_TOKEN`
- `DATABASE_URL`
- `ADMIN_IDS`
- `REQUIRED_CHANNEL=@fox_frenzy`
- `REQUIRED_CHANNEL_URL=https://t.me/fox_frenzy`
- `CLAIM_KEYWORD=هور`
- `CLAIM_COOLDOWN_SECONDS=300`

## نکته عضویت اجباری
بات را در کانال `@fox_frenzy` ادمین کن تا Telegram API بتواند عضویت کاربران را با اطمینان بررسی کند.

## اجرای Railway
Procfile:
`worker: python bot.py`

اگر Railway هنوز از build قبلی استفاده کرد، یک redeploy با پاک‌کردن cache انجام بده.

## پنل
ادمین با `/admin` وارد پنل می‌شود. برای پیام همگانی، متن ارسالی برای همه کاربران ثبت‌شده ارسال می‌شود و ادمین هم از قابلیت‌های پنل محروم نیست.

## محدودیت مهم
در این نسخه امکان شرط‌بندی/برد و باخت هور پوینت بین کاربران عمداً وجود ندارد؛ بازی‌ها فقط پاداش ثابت غیرقابل‌شرط‌بندی می‌دهند.
