# راهنمای مینی‌اپ روبی — مو به مو

همه‌ی کد نوشته شده و آماده‌ست. تو فقط باید این مراحل رو دنبال کنی. هر مرحله رو با ✅
علامت بزن که جا نمونه.

قبل از شروع: این پوشه (`miniapp/`) رو دقیقاً **کنار `bot.py` و `database.py`**
توی همون ریپوی گیت‌هاب باتت بذار (بریزش توی همون پوشه‌ای که این دوتا فایل توش هستن).
ساختار نهایی باید این شکلی باشه:

```
(ریشه‌ی ریپو)/
  bot.py
  database.py
  requirements.txt
  ...
  miniapp/
    README.md
    backend/
      main.py
      auth.py
      requirements.txt
      .env.example
    frontend/
      index.html
      style.css
      app.js
```

---

## مرحله ۱ — ساخت دکمه‌ی Mini App توی BotFather

۱. توی تلگرام برو به چت `@BotFather`
۲. بنویس `/mybots` و باتت رو از لیست انتخاب کن
۳. بزن روی **Bot Settings**
۴. بزن روی **Menu Button**
۵. بزن روی **Configure Menu Button**
۶. یه URL ازت می‌خواد — فعلاً همین رو بفرست: `https://example.com`
   (این یه مقدار موقته، توی مرحله‌ی ۴ همین پایین عوضش می‌کنیم)
۷. یه اسم کوتاه براش بفرست، مثلاً: `روبی`

فعلاً همین کافیه، برمی‌گردیم سراغش.

---

## مرحله ۲ — بالا بردن سرویس جدید روی Railway

(فرض می‌کنم همین الان `bot.py`ت روی Railway داره اجرا می‌شه — یعنی از قبل یه
پروژه‌ی Railway داری.)

۱. وارد [railway.app](https://railway.app) شو و همون پروژه‌ای که `bot.py`ت توشه رو باز کن
۲. بالا سمت راست بزن روی **+ New**
۳. گزینه‌ی **GitHub Repo** رو بزن و همون ریپویی که `bot.py` توشه رو انتخاب کن
   (بله، یه سرویس دوم از همون ریپو می‌سازیم)
۴. بعد از ساخته شدن سرویس جدید، روش کلیک کن تا تنظیماتش باز بشه
۵. برو تب **Settings**
۶. توی بخش **Root Directory** بنویس: `miniapp/backend`
۷. توی بخش **Start Command** بنویس:
   ```
   uvicorn main:app --host 0.0.0.0 --port $PORT
   ```
۸. اگه بخش **Build Command** یا Builder ازت پرسید، بذار خودش تشخیص بده
   (چون `requirements.txt` توی همون پوشه هست، خودش می‌فهمه پایتونیه)

---

## مرحله ۳ — تنظیم متغیرهای محیطی (Variables)

همین سرویس جدید (نه سرویس bot.py) رو باز کن، برو تب **Variables**، و این دوتا رو اضافه کن:

| Key | Value |
|---|---|
| `BOT_TOKEN` | دقیقاً همون مقداری که توی سرویس bot.py هم داری |
| `DATABASE_URL` | دقیقاً همون مقداری که توی سرویس bot.py هم داری |

⚠️ خیلی مهم: این دوتا باید **عیناً همون مقدارهای سرویس bot.py** باشن، چون مینی‌اپ
باید به همون ربات و همون دیتابیس وصل بشه، نه یه چیز جدید.

(برای کپی کردنشون: برو سراغ سرویس قبلی bot.py → تب Variables → مقدار هرکدوم رو
کپی کن → بیا توی سرویس جدید پیستش کن.)

بعد از ست کردن این دو متغیر، Railway خودش یه بار دیگه دیپلوی می‌کنه.

---

## مرحله ۴ — گرفتن آدرس عمومی و گذاشتنش توی BotFather

۱. توی همون سرویس جدید (مینی‌اپ)، برو تب **Settings**
۲. توی بخش **Networking** بزن روی **Generate Domain**
۳. یه آدرسی بهت می‌ده شبیه این: `https://ruby-miniapp-production.up.railway.app`
   این آدرس رو کپی کن
۴. برگرد به چت `@BotFather`
۵. بنویس `/mybots` → باتت رو انتخاب کن → **Bot Settings** → **Menu Button** →
   **Configure Menu Button**
۶. این بار همون آدرس واقعی رو بفرست (نه example.com)

---

## مرحله ۵ — تست کردن

۱. برو توی چت باتت توی تلگرام (گوشیت، نه دسکتاپ — بهتر کار می‌کنه)
۲. پایین کنار جعبه‌ی تایپ، باید یه دکمه‌ی منو با اسمی که انتخاب کردی («روبی») ببینی
۳. بزن روش
۴. باید صفحه‌ی پروفایل روباهت باز بشه: اسم، سطح، روب‌پوینت، آمار شکار و جغد و...
۵. از پایین بزن روی «لیدربرد» و دسته‌های مختلف رو امتحان کن

اگه پیام «هنوز توی بات ثبت‌نام نکردی» دیدی، یعنی قبلش یه پیام (مثلاً `/start`) به
بات نداده بودی — یه پیام بده و دوباره مینی‌اپ رو باز کن.

اگه چیزی باز نشد یا خطا داد، برو سراغ بخش «اگه مشکلی پیش اومد» پایین همین فایل.

---

## اگه مشکلی پیش اومد

- **صفحه‌ی سفید / چیزی باز نمی‌شه:** توی Railway سرویس جدید رو باز کن → تب
  **Deployments** → آخرین دیپلوی → **View Logs**. اگه خطایی چاپ شده، همونو برام بفرست.
- **نوشته "initData نامعتبر":** یعنی `BOT_TOKEN` توی سرویس جدید با توکن واقعی باتت
  یکی نیست. دوباره چک کن عین هم باشن.
- **نوشته "هنوز توی بات ثبت‌نام نکردی":** طبیعیه، یعنی اون کاربر هنوز به بات پیام
  نداده؛ ربطی به باگ نداره.
- **دکمه‌ی منو توی BotFather اصلاً ظاهر نمی‌شه:** تلگرام گوشیت رو کامل ببند و
  دوباره باز کن (کش می‌کنه).

## این نسخه الان چی داره و چی نداره

**داره:**
- صفحه‌ی پروفایل: اسم روباه، سطح، روب‌پوینت، رتبه، شکار، روب روب، روباه نجات‌یافته،
  جغد، رفرال، شکم روباه
- لیدربرد با ۵ دسته: روب‌پوینت، شکار، جغد، روباه نجات‌یافته، رفرال

**نداره (برای نسخه‌ی بعدی گذاشتم، چون پیچیده‌تره و نیاز به تصمیم داره):**
- مارکت روبی (چون هر آیتمش مال یه گپ/شهر خاصه، نه سراسری؛ باید اول تصمیم بگیریم
  کاربر از کدوم گپش مارکتش رو ببینه)
- خرید/فروش و هر چیزی که پول جابه‌جا می‌کنه (بانک، کازینو، انتقال)
- مدیریت شهر/شهرداری

وقتی این نسخه رو تست کردی و راضی بودی، بگو کدوم بخش بعدی رو اضافه کنم.
