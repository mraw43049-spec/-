نسخه اصلاح‌شده موشک روباهیو
- رابط موشک در مینی‌اپ به چالش تمرینی انفرادی ۱۰ ثانیه‌ای تبدیل شده است.
- ضریب نمایشی از -1.00 شروع می‌شود و کاربر می‌تواند هدف تمرینی را تعیین کند.
- این چالش موجودی را تغییر نمی‌دهد و شرط/برداشت کازینویی غیرفعال شده است.
- فایل‌های پروژه در این ZIP هستند؛ هیچ تغییری روی Railway یا GitHub منتشر نشده است.
